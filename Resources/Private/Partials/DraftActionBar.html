Shared sticky bottom action bar for every draft-gated tab, so the draft lifecycle (Publish / Discard) sits in the same place on all of them instead of top on some and bottom on others. Arguments: isDraftEditable (bool) — a draft exists AND this user owns the lock scope (string) — draft scope for the publish/discard POST currentUrl (string) — returnUrl after publish/discard showAutosaveStatus (bool, optional) — ThemeDesigner autosave status showReset (bool, optional) + uri_reset (string) — ThemeDesigner only Publish/Discard live only here; the top DraftBanner is rendered with `hideActions: 1` on these tabs so the buttons are not duplicated. The `.simplecmp-sticky-actions` style ships with the DraftBanner partial (rendered on every draft tab).
