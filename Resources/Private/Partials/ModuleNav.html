{namespace core=TYPO3\CMS\Core\ViewHelpers} Shared tab nav for the simplecmp_detections module. Three tabs reflecting the 3-table architecture: - Detections — observation log (DetectionReviewController) - Dienste — registry index regardless of source (RegistryListController) - Bibliothek — bundled library browser + Adopt action (LibraryBrowserController) The three URIs are assigned by each controller — we don't construct them in Fluid because Extbase's URI builder is scoped to the current controller and can't switch cleanly. Pass `active="detections"|"registry"|"library"` from the parent template to drive the active-state styling.
