----

TYPO3 integration for `SimpleCMP <https://github.com/SimpleCMP/simplecmp>`__ —
the open-source consent manager with development-time tracker auto-
detection, a shared service database, and optional CMS-bridge webhook
alerts for unknown trackers spotted in production.

This extension is **pre-1.0** and tracks the upstream SimpleCMP
library's own pre-release status. APIs and settings may change
between minor versions.
